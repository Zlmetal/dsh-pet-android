# 大肥鱼桌宠 · dsh-pet Android Remote

把 [dsh-pet](https://github.com/PC2005-cloud/dsh-pet)（DeepSeek Harness 的网页桌宠）搬到 Android 主屏，并让手机**远程**连上跑在 NAS / 服务器上的 DSH——不用在本机跑 DSH，也不用装 DSHA。

一条蓝色的大肥鱼常驻在手机桌面上：会待机、会碎碎念、会显示 DSH 的工作状态和余额；拖一拖能甩出去撞墙反弹，点一下会 Q 弹。双击它，直接打开**跟网页端同一份的会话**，能看图、能发附件。

![Android](https://img.shields.io/badge/Android-8.0%2B-3DDC84?logo=android&logoColor=white)
![version](https://img.shields.io/badge/version-1.0.0.16-blue)
![size](https://img.shields.io/badge/APK-36.0MB-lightgrey)
![license](https://img.shields.io/badge/license-MIT-green)

> 不需要 root，不需要 Xposed / LSPosed，不需要 ADB / Shizuku，也不需要无障碍服务。
> 它就是一个普通的悬浮窗 App，通过 HTTP(S) 连上你的 DSH——本机 `127.0.0.1` 也行，公网域名也行。

## 相对上游改了什么

### 一、支持远程 DSH（本项目最大的改动）

上游只认 `http://127.0.0.1:<端口>`：它假设 DSH 和桌宠 App 跑在同一台手机上，所以地址是写死的本机回环。

本版把它拆成了真正的客户端：

- **完整地址**：`https://dsh.example.com`、`http://192.168.2.5:13080`、`127.0.0.1:38859` 都行，`http://` 和 `https://` 都支持（TLS 走标准 `SSLSocket`）；
- **密码登录**：给 [dsh-access-gate](https://github.com/deepseek-ai/dsh) 那种网关留了密码框，App 会自己走完登录流程；
- **Cookie 自动续期**：网关 cookie 默认 7 天过期，过期后 App 检测到被 302 踢走会**自动重新登录**，不用你手动重填；
- **IPv4 优先 + 多地址兜底**：域名同时解析出 IPv6 但它连不通时，会逐个地址重试，不再傻等第一个。

登录流程（App 里自动做的，写在这里方便你排查）：

```
POST {origin}/-/auth/login     password=...&next=/   → 302 + Set-Cookie: dsh_gate_token
GET  {origin}/?token=<launch>                        → 303 + Set-Cookie: dsh-auth-<hash>
POST {origin}/api/...                                 → 两个 cookie 都带上
```

两层 cookie 缺一层都会失败：网关那层缺了会被 302 踢去登录页，DSH 自己那层缺了 `/api` 会回 401。App 在 401 时会拿上次登录的 launch token 补一次再重试。

### 二、App 里自带对话（双击就进）

上游的双击是「打开 DSHA」，本版改成**打开对话**：

- 左侧会话抽屉，按**工作区分组**（`临时工作` / `im` ……），组头可折叠，右上角「新」开新会话；
- 列表加载的是 **DSH 网页端真实的会话**，不是插件那个 `sessionId` 写死的独立身份——你在电脑上聊过的，手机上能看到、能接着聊；
- 打开会话先拉最近几条，往上翻再拉更早的（分页锚点用未过滤的最小 `seq`）；
- 发消息后用 `session/wait` 阻塞到这一轮跑完，只渲染**最终结果**——思考过程、工具调用、工具返回、中间步骤全部丢掉，不再糊满屏幕；
- 纯表情消息整条跳过，`[表情: …]` 这种给网页端看的标记不会原样露在手机上。

用到的接口（都是网页端同一套 `/api`，不是插件私有的）：

| 接口 | 用途 |
| --- | --- |
| `POST /api/session/list` | 会话列表（含工作区归属） |
| `POST /api/session/events` | 拉某会话的历史消息 |
| `POST /api/session/create` | 新建会话 |
| `POST /api/session/prompt` | 发一条消息 |
| `POST /api/session/wait` | 等到这一轮跑完 |
| `POST /api/session/uploadFileBinary` | 上传图片 / 附件 |
| `GET /api/file?path=…` | 读 `present` 声明的文件 |

### 三、图片和附件

- 回复里带的图片**直接显示**在气泡里，点开看大图；
- `present` 出来的文件做成附件卡片，**默认不下载**（手机流量和存储都省着），卡片上写着大小，点一下才下到 `下载/`；
- **下载过一次以后再点，直接交给系统里能打开它的 App**，不再重复下载；本机没有能打开的 App 时会提示「没 App 能打开 · 点一下重新下载」；
- 自己发的图片 / 附件：先拿本地 Uri 立刻画出来，不等服务器回图；发送时走 `uploadFileBinary`，超大文件（>24 MB）直接拦下；
- 历史里那些服务端已经不给读的老附件，卡片上明说「历史附件已不可取，重发一次才能下」，不会让你点半天没反应。

### 四、修了上游一个会吃数据的老 bug

上游的 `DshHttp.readAll()` 先把响应转成 `String`，再按**字符**下标去切 `Transfer-Encoding: chunked` 的分块。但 HTTP chunk 的长度是**字节数**——中文一个字占 3 字节，于是 32768 字节的 chunk 只被切成 32768 个字符，JSON 正好断在中间，报错长这样：

```
解析失败：Unterminated object at character 32768
```

会话一多、余额一大就必现，症状是「会话抽屉读不出来，聊天区把整坨原始 JSON 当消息渲染」。

本版把整条链路改成**全字节流**：`readAllBytes` → 按字节找 `CRLFCRLF` 切头部 → `dechunkBytes` 按字节解分块 → 转码时才拼 `String`。实测同一份 38767 字节的响应，旧写法只剩 32768 字符、尾部截断，新写法完整解析。

### 五、界面与其它

- **顶栏按钮挪到左边**：「≡」「新」在左，标题居中，「关闭」在最右——单手够得着；
- **去掉「赞赏作者 ♥」**：这个改版不设收款入口；
- **去掉 DSHA 依赖**：菜单里不再有「打开 DSH」「获取 DSHA ↓」，也不再检测 `dsh.android.client` 装没装；连不上时给的是「设置 DSH 地址与密码」；
- 版本从上游的 1.0.0.1 一路走到 **1.0.0.16**（`versionCode` 10016），签名跨版本复用，可以直接覆盖安装。

## 它是什么

DSH（DeepSeek Harness）自带的桌宠是一个网页组件，只在浏览器里出现。这个项目把它做成了 Android 悬浮窗：

- 用 `TYPE_APPLICATION_OVERLAY` 常驻桌面，切到任何 App 都还在；
- 用 WebView + Canvas 逐帧绘制 106 个 VP9-alpha 动画，没有黑底、没有原生播放控件；
- 用前台服务保活，锁屏、切后台都不掉；
- 通过 HTTP(S) 读取 DSH 的工作状态、余额和碎碎念，地址可以是本机、局域网或公网；
- 用 Java 实现了一套简单的物理：拖动、甩飞、撞墙反射、接住、好感度。

它**不再依赖 DSHA**。DSHA 是「在手机上把 DSH 跑起来」的客户端，本版不关心 DSH 跑在哪——只要你的手机能访问到那个 DSH 的地址，桌宠就能用。

## 数据插件（状态 / 余额 / 碎碎念 / 对话的数据源）

这四项数据来自 **dsh-pet** 插件——就是最上面那张表里的「原版插件」，本仓库**不自带**它：

- 仓库与文档：<https://github.com/PC2005-cloud/dsh-pet>
- 安装：在 DSH 的插件页搜索 `dsh-pet` 安装，装完重启 DSH

**建议把显示位置设成「窗口和桌面都不显示」（`display: "none"`）。** 这样插件只当数据源，网页端和桌面上不会再多冒出一只宠物；App 照旧从它的路由取数据。

验证：

```sh
curl -s http://127.0.0.1:13080/dsh-pet-7340/state | head -c 120
```

返回带 `"sections"` 的 JSON 即正常。

| 接口 | 用途 |
| --- | --- |
| `GET /dsh-pet-7340/state` | 工作状态 / 余额缓存 / 会话事件 / 宠物语录 |
| `POST /dsh-pet-7340/balance` | 触发余额刷新 |
| `POST /dsh-pet-7340/whisper?pet=main&surface=web` | 生成碎碎念 |
| `GET/POST /dsh-pet-7340/chat` | 插件自带的简易对话（本版聊天界面**不用**它，走 `/api`） |

> 状态与余额不校验显示模式，`none` 下照常可用；碎碎念要求显示模式覆盖 `web`。
>
> 如果喜欢这个插件，欢迎去 [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet) 给作者点个 ⭐ **Star**——素材和创意都是人家的。

## 安装

1. 下载 `pet-1.0.0.16.apk`（见文末「下载」）；
2. 点击安装，首次需允许「安装未知应用」；从上游 1.0.0.1 或本仓库旧版升级都可以直接覆盖，配置不会丢；
3. 打开「大肥鱼桌宠」→ 点「授予悬浮窗权限」→ 在系统设置里允许「显示在其他应用上层」；
4. Android 13+ 建议允许通知权限（前台服务通知，可设为静默）；
5. 点「手动填写」，填 DSH 地址和密码（见下一节）；
6. 点「启动大肥鱼」，返回桌面即可看到宠物。

**MIUI / HyperOS 额外一步**：在「应用设置 → 大肥鱼桌宠 → 权限管理」里允许「后台弹出界面」，否则双击宠物打不开对话界面。

**其他 ROM**：

- 三星：设置 → 应用程序 → 桌宠 → 权限 → 允许显示在其他应用上层；
- ColorOS / OriginOS：应用管理 → 桌宠 → 权限管理 → 悬浮窗；
- 原生 Android：设置 → 应用 → 特殊应用权限 → 显示在其他应用上层。

## 首次使用：填地址

点主界面「手动填写」，一个对话框两个框：

| 输入框 | 填什么 | 例子 |
| --- | --- | --- |
| DSH 地址 | 完整地址，`https://` 别省 | `https://dsh.example.com`<br>`http://192.168.2.5:13080`<br>`127.0.0.1:38859` |
| 访问密码 | dsh-access-gate 的密码；没套网关就留空 | `********` |

点「保存并检测」，App 会立刻握手：

- 成功 → 状态卡「DSH 连接」变绿，端点那行显示实际连上的地址和来源（`manual` / `cache` / `scan`）；
- 失败 → 端点那行把原因写出来（连不上、证书问题、密码错、401、插件没装……），不用瞎猜。

「清除」会删掉手动地址和密码，回到自动查找（适合本机 `127.0.0.1` 场景）。

> **密码存在哪？** 应用私有 `SharedPreferences`，明文（跟大多数自建 App 一样）。手机没 root 的话别的 App 读不到；如果你在意，可以给 DSH 单独设一个只读密码。

- 甩出初速上限 2200 px/s；
- 位置用浮点锚点 `anchorX/anchorY` 维护，换动作不会累积取整误差。

### 对话界面

- **左上「≡」**：开合会话抽屉；
- **左上「新」**：新建会话；
- **抽屉里按工作区分组**，组头那一行点一下折叠 / 展开；绿点＝当前会话；
- **点会话**：加载最近几条，往上滑到顶再加载更早的；
- **输入框左边「＋」**：发图片或附件（二选一，单次 ≤ 24 MB）；
- **图片**：直接在气泡里显示，点一下看大图；
- **附件卡片**：没下过写「点一下下载 · 12.3 KB」，下过的写「已下载 · 点一下打开」；
- **右上「关闭」**：回到桌面。

### 大小调节

菜单 →「大小 ▸」打开深色卡片，拖动滑块 50%–200%，宠物实时缩放；松手写入 `SharedPreferences`，下次启动保持；点「重置 100%」恢复默认，「完成」关闭。

只缩放宠物窗口，气泡、菜单、文字不跟着变，避免大字挡住桌面。

### 显示位置

对应网页端桌宠的右键菜单「显示位置」：

- 仅网页：只在浏览器里出现；
- 仅桌面：只在桌面悬浮窗出现；
- 两者：两边都显示（推荐，碎碎念需要 `web` 或 `both`）；
- 都不：都隐藏（相当于关闭显示器）。

命令通过 `POST /dsh-pet-7340/pet-display {"id":"main","display":"web|desktop|both|none"}` 下发。

## 与 DSH 的联动机制

### 轮询

App 每 2 秒请求一次：

```
GET {origin}/dsh-pet-7340/state
```

返回结构（节选）：

```json
{
  "counter": 1793330785636,
  "sections": {
    "workStatus": { "data": { "state": "working", "task": "…" } },
    "balance": { "data": { "wallets": [ { "total": "4.60", "currency": "CNY" } ] } },
    "notify": { "data": { "type": "session/event", "event": { "type": "turn/end" } } }
  },
  "pets": { "main": { "say": { "counter": 123, "text": "…" } } }
}
```

### 状态映射

| `workStatus.state` | 宠物动作 | 文案示例 |
| --- | --- | --- |
| `thinking` | 思考冒泡 | 「让我想想…」 |
| `working` | 忙碌点按 | 「正在干活…」 |
| `waiting` | 原地踱步张望 | 「在等你确认哦」 |
| `success` | 雀跃庆祝 | 「搞定啦！」 |
| `error` | 垂头叹气冒汗 | 「出错了…」 |

状态变化且有内置文案时，用原生气泡显示 6–7 秒。

### 余额

`/state` 里的 `sections.balance` 是服务端缓存，可能几分钟不更新。所以「查看余额」不是直接读缓存，而是：

1. `POST /dsh-pet-7340/balance` 触发服务端刷新；
2. 等 1 秒；
3. 再 `GET /state` 取 `wallets[0].total`；
4. 气泡显示 `余额 ¥x.xx`。

三种失败会分开说：没连上 DSH / 连上了但查不到该供应商的余额 / 正常。

### 碎碎念

1. `POST /dsh-pet-7340/whisper?pet=main&surface=web`；
2. 返回 `{"ok":true,"text":"…","image":"…"}` 就显示 `text`；
3. 如果返回 `{"ok":false,"reason":"pet-not-displayed"}`（DSH 重启后显示模式回到 `desktop`），App 会自动 `POST /pet-display {"id":"main","display":"both"}` 再重试一次；
4. 仍失败则用 8 句内置文案兜底，不至于「点了没反应」。

### 碎碎念推送

网页端（或其他端）产生的 `pets.main.say` 也会被轮询读到：counter 变化且文本与最近一次不同，就弹气泡 7 秒；首帧只记录 counter，避免一启动就弹旧消息。

## 常见问题

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 宠物没出现 | 没给悬浮窗权限 | 设置里允许「显示在其他应用上层」后重新启动 |
| 状态 / 余额 / 碎碎念没有 | DSH 没连上，或插件没装 | 看端点那行写的什么原因；`curl {origin}/dsh-pet-7340/state` 自测 |
| 端点显示「未运行」，但浏览器能打开 | 域名优先解析到连不通的 IPv6 | 1.0.0.2 起已改 IPv4 优先 + 逐地址重试；仍失败就用「手动填写」直接填 IP |
| 填了密码还是被踢去登录页 | 密码错，或网关路径不是 `/-/auth/login` | 用浏览器登一次看真实路径；本项目按 dsh-access-gate 的默认实现 |
| 聊到一半突然全失败，过一会儿又好了 | 网关 cookie 到期（默认 7 天） | App 会自动重登；若一直不行，重新点一次「保存并检测」 |
| 会话抽屉报「Unterminated object at character 32768」/ 聊天区把 JSON 当消息 | 1.0.0.15 及更早的 chunked 按字符切分 bug | 1.0.0.16 起已按字节解，升级即可 |
| 「读不到会话：解析失败」其它 JSON 错误 | 网关返回了 HTML（反代没转发 `/api`） | 确认反代把 `/api`、`/dsh-pet-7340` 都转发给 DSH |
| 点碎碎念提示 `pet-not-displayed` | DSH 重启后显示模式回到 desktop | App 会自动改回 both；仍失败去网页端右键菜单设「两者」 |
| 双击打不开对话 | MIUI 拦截后台弹出 | 允许「后台弹出界面」 |
| 附件点一下没反应 | 历史附件服务端已不给读 | 卡片上会写「已不可取」；让对面重发一次 |
| 下载过的附件再点提示「没 App 能打开」 | 手机里没有能处理这种类型的 App | 装个文件管理器 / Office / 对应阅读器；卡片上有「点一下重新下载」兜底 |
| 悬浮窗过一会消失 | 系统省电/后台清理 | 省电策略「无限制」、允许自启动、加白名单 |
| 黑底 / 不动 | WebView 版本太旧 | 更新 Android System WebView 或 Chrome |
| 点一下会飘 | 旧版本取整误差 | 4.1 起已用浮点锚点；若仍偶发多为动画本身位移 |

更多排查：看 `/sdcard/Android/data/com.dsha.pet/files/poll.log`，里面记录每次轮询的 URL 和返回前几十个字符。

## 性能与耗电

- 待机时只做 2 秒一次的 HTTP 轮询 + 视频播放，CPU 占用通常 < 2%；
- 飞行 / 拖动时按屏幕刷新率绘制（120Hz 屏可到 120fps）；
- 前台服务常驻会显示一条通知，可设为静默；
- 106 个动画按需加载，首次播放某个动作有几十毫秒解码延迟，之后走缓存。

## 隐私与安全

- 不联网上传任何数据，不包含统计 SDK、广告 SDK；
- 只访问你填的那一个 DSH 地址，不发往别处；
- 地址与密码、好感度、大小、上次打开的会话等设置只存在应用私有 `SharedPreferences`；
- 下载的附件存在 `下载/`（应用外部目录，需要时可自行删除）；
- 诊断日志写在 `Android/data/com.dsha.pet/files/poll.log`，仅本机可读；
- 不读取通讯录、短信、位置、相册，不申请无障碍。

**公网暴露提醒**：把 DSH 直接挂公网而不套密码网关，等于把控制台交给全世界。本项目支持密码登录就是为了这个——请务必用网关或反代加一层认证。

## 从源码构建

依赖：JDK 17、`aapt`、`zipalign`、`apksigner`、`android-34` 的 `android.jar`（或 Android SDK build-tools）。

```bash
./build.sh     # 生成 build/pet.apk
./deploy.sh    # 按 versionName 导出 build/pet-<ver>.apk
```

或者直接推 `main` 分支，GitHub Actions 会打好 APK 传成 artifact `pet-apk`（`.github/workflows/build.yml`，签名 keystore 从 secret `KEYSTORE_B64` 还原）。

构建流程：

1. `aapt package -m -J build/gen` 生成 `R.java`；
2. `aapt package -F build/base.apk -A assets` 打包资源与素材；
3. `javac -encoding UTF-8 -source 1.8 -target 1.8` 编译 Java；
4. `d8` 生成 `classes.dex`；
5. `zip` 把 dex 塞进 APK；
6. `zipalign -f 4` 对齐；
7. `apksigner` 用 `signing/debug.keystore` 签名。

目录结构：

```
app/src/main/
├── AndroidManifest.xml
├── java/com/dsha/pet/
│   ├── MainActivity.java     # 控制面板、地址与密码填写
│   ├── ChatActivity.java     # 会话抽屉 + 聊天流 + 图片/附件
│   ├── PetService.java       # 悬浮窗、动画、物理、菜单、轮询
│   ├── DshEndpoint.java      # 端点发现（手动 / 缓存 / 扫描 / 深度）
│   ├── DshHttp.java          # HTTP(S)、chunked 按字节解码、两级 cookie
│   ├── DshApi.java           # /api 封装（会话、发消息、文件）
│   ├── BootReceiver.java     # 开机自启
│   └── WatchdogReceiver.java # 心跳看门狗
├── assets/
│   ├── pet.html              # Canvas 播放器（由 scripts/gen_html.py 生成）
│   ├── webm/                 # 106 个动画
│   ├── bbox.json             # 每个动画的内容包围盒
│   ├── actions.json          # 动作分类
│   └── font/cute.ttf         # 站酷快乐体
└── res/drawable/ic_launcher.png
```

素材说明：`assets/webm` 来自 dsh-pet 的 `assets/webm`，按中文名排序复制为 `001.webm`…`106.webm`；`bbox.json` 用 ffmpeg（`-c:v libvpx-vp9` 解 alpha）+ 逐帧统计生成。
